# NEXORA release and paper-forward evidence checklist

Status is evaluated against the current local workspace. **Nothing in this checklist enables live trading.** `LIVE_TRADING_ENABLED=false` remains an invariant before and after every item is reviewed.

## Current evidence

### Repeatable software-test lanes

- `npm run test:smoke` — API contract/auth and isolated startup/port-safety checks.
- `npm run test:unit` — deterministic domain and journal-statistics tests.
- `npm run test:integration` — persistence, worker, lifecycle, research, Telegram mocks, and migration integration.
- `npm run test:recovery` — process-crash and transaction-replay matrix.
- `npm run test:security` — high-confidence credential literal scan and `.env.example` placeholder checks.
- `npm test` — complete regression suite; `npm run check` — syntax checks.

Paper-forward evidence is intentionally not a software-test lane. It requires an owner-selected provider, real broker-fed paper closes, critical-slice review, and the evidence threshold below; synthetic runs never count.

## Owner-gated prerequisites

Before any realistic paper-forward run, the owner must choose and authorize the broker/market-data provider and news-calendar source, provide verified XAUUSD contract/account metadata through an approved secret/config path, and review the provider's official contract/terms and operational semantics. Do not paste credentials into chat or source control. No default provider choice is implied here.

After a provider is selected, run adapter contract tests for health, quote/candle freshness and gaps, timezone, malformed payloads, timeout, rate limit, reject/disconnect, unknown order state, reconnect, and account/contract metadata. Then conduct a monitored paper-forward run, review every transition/snapshot and critical slice, and preserve the baseline, dataset hash, build/schema/strategy/config versions, costs, and rollback condition.

Passing all paper gates still does not create a live route or authorize live trading. Any future live capability requires a separate product/security review and explicit user decision; this workspace currently contains no live adapter.
